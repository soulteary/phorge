# Phorge 维护文档索引

本目录链接当前源码的部署与维护入口。发布记录用于追溯当时的范围，当前操作应以
这里链接的维护文档、Compose 和配对源码为准。跨仓库链接采用相邻的
`phorge-fork/`、`gorge/` checkout；其他布局运行验收时传 `--gorge-dir`。

## 阅读顺序

1. [项目说明](../README.md)：项目用途和本 fork 的入口。
2. [容器部署](../DOCKER.md)：默认栈、配置优先级、各域接入、旧实现边界、验证依赖。
3. [生产切换](../PRODUCTION-CUTOVER.md)：生产认证与只读授权、邮件 native 模式、
   搜索/图片验收、九项清理交接和回退。
4. [运维工具](../scripts/operations/README.md)：停写备份、数据库/文件隔离恢复、
   Elasticsearch 外部快照恢复、告警、容量与尚未实现的运维能力。
5. [PHP 运行库维护](../support/runtime/README.md)：来源身份、补丁记录、解析器/映射、
   manifest 更新与 PHP 版本支持范围。
6. [中文本地化](../I18N-zh_CN.md)：翻译来源、提取、格式验证与维护流程。

[发布记录](../RELEASE_NOTES.md)与 [2026.10.08-r1 发布准备](releases/2026.10.08-r1.md)
记录当前候选范围和发布步骤；[2026.10.07-r2 发布准备](releases/2026.10.07-r2.md)
保留版本历史。两仓协议与 Go 服务的完整说明见 [Gorge 模块索引](../../gorge/docs/README.md)。

## 选择验证入口

- 修改保留运行库或 PHP 响应协议：运行 [运行库维护检查](../DOCKER.md#内置-php-兼容运行库)
  和对应契约；涉及 managed 文件才按运行库维护流程更新 manifest。
- 修改跨仓业务或准备交付：使用 [独立 Docker 交付验收](../DOCKER.md#独立-docker-交付验收)。
  它需要两个源码 checkout，自动启动临时真实依赖；`--check` 仅检查隔离配置。
- 审核生产配置：运行 [生产 preflight 和只读切换检查](../PRODUCTION-CUTOVER.md)。
  通过不等于真实邮件送达、索引业务覆盖、像素等价或恢复完成。
- 验证备份可用：使用 [恢复演练和外部搜索恢复](../scripts/operations/README.md)。
  数据库导入、卷字节一致和业务恢复是不同证据，不能互相替代。

当前 Docker/完整配对契约基线为 PHP 8.3。PHP 8.4/8.5 的 CI 矩阵覆盖保留运行库、
维护工具和响应安全，尚不宣称完整应用、迁移或生产工作负载兼容。
完整配对验收也不覆盖认证后浏览器业务流程、第三方真实供应商投递或生产性能；
部署者仍需保留这些验证及 RPO/RTO、授权和恢复证据。
