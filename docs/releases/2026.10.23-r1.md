# Phorge 2026.10.23-r1 发布准备

状态：准备中，尚未发布。必须配对 Gorge `2026.10.23-r1`。

已发布基线仍为 `2026.10.08-r1`。本版包含 #41 的 PHP 8.3.36 与 session 安全加固，以及 #42 的发布准备。此前 Gorge `2026.10.22-r1/r2` 已发布，但不能作为本次安全配对证明；不得覆写其标签或 Release。

1. 合并本 PR，取得最终 Phorge 40 字符 SHA。
2. 在 Gorge `deploy/release/source-pair.json` 固定该 SHA 和本版本，合并对应准备 PR。
3. 在 Gorge 最终提交创建新标签 `2026.10.23-r1`，执行 Release 的完整十四镜像与真实后端配对验收。
4. 确认 Gorge Release 公开，核对 manifest 的 Phorge SHA 等于本 PR 合并提交、Gorge SHA 等于新标签提交，并核对全部服务 digest。
5. 仅在上述门禁通过后，在 manifest 对应 Phorge SHA 创建 `2026.10.23-r1` tag 和公开 Release。正文采用本提交的 RELEASE_NOTES.md，并追加实际的源码对、Gorge Release 和 manifest 链接。
6. 备份和临时环境升级验证后再部署生产；Phorge PHP consumer 先于 Gorge db-api 服务升级。

本准备记录不构成发布或生产验收证明。历史版本及标签保持不可变。
