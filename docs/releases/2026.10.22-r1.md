3. 在 Gorge 最终验收提交创建并推送 `2026.10.22-r1` 标签，触发十四项候选镜像与配对验收。

5. 在 manifest 对应的 Phorge SHA 创建同版本 tag 和 GitHub Release；正文使用 `RELEASE_NOTES.md`，链接 Gorge Release 和 manifest。
