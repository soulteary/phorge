# Phorge 2026.10.23-r2 发布准备

状态：准备中，尚未发布。必须配对 Gorge `2026.10.23-r2`。

`2026.10.23-r1` 的 Gorge tag 保留不变；其 Release 工作流 39880254510 在
`base-image-build` 被安全门禁阻断，没有公开 Release。新 PHP 8.3.36 镜像包含
libcurl4t64 `8.14.1-2+deb13u7`，旧 `20261006T000000Z` Debian 快照却只提供
依赖 u5 运行库的开发包，导致 APT 构建失败。

本版固定 Debian 快照为 `20261023T000000Z`；官方安全快照索引确认 curl 运行库和
开发包均为 `8.14.1-2+deb13u7`。安全 CI 使用与生产验收一致的 PHP digest、APCU
版本/校验和及 Debian snapshot 实际构建应用镜像，并在该镜像中检查 PHP 和已安装
的 session 设置，不覆盖镜像 INI。PHP 安全版本和所有验收门禁继续保留。

合并后将本 PR 最终 SHA 固定到 Gorge r2 source-pair.json；Gorge 最终 SHA 的 CI、
文档和发布构建通过后创建新的 r2 tag。只有十四候选和完整配对验收成功、公开 manifest
核对无误后，才在 manifest 对应的 Phorge commit 创建同版本 tag/Release。
